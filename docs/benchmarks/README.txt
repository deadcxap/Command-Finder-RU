Опубликованные результаты сравнения моделей

Архив raw-reports.json.gz содержит JSON-объект с 23 исходными отчётами.
Ключи объекта — идентификаторы запусков run_id из summary.json и summary.csv.
Один запуск содержит результаты русского и английского поиска: всего 46 строк сводки.

Перед публикацией локальные пути заменены путями относительно репозитория.
Поля report_path, onnx_dir и другие пути .benchmarks/... обозначают исторические
места хранения артефактов. Эти файлы и модели не входят в репозиторий; данные
отчётов сохранены в архиве. Архив предназначен для изучения результатов,
а не для передачи в benchmarks.suite или повторного запуска старых заданий.
Для нового измерения используйте инструкции в benchmarks/README.md.

Поле manifest_sha256 в summary.json относится к опубликованному manifest.json.
original_manifest_sha256 сохраняет контрольную сумму исходного манифеста до
замены путей. Контрольные суммы кода, словаря, запросов и моделей в исходных
данных оставлены историческими; числовые результаты измерений не изменены.
